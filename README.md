#  Portfólio Pessoal

Este projeto consiste em um site simples de portfólio desenvolvido com o objetivo de reunir algumas informações sobre mim e apresentar projetos desenvolvidos durante minha jornada de aprendizado em programação.

## Sobre o projeto

O site foi criado como forma de praticar desenvolvimento web e organizar alguns trabalhos realizados durante meus estudos.

## Estrutura do site

O portfólio contém:

- Uma seção **Sobre mim** com um breve resumo da minha trajetória
- **Três projetos** com pequenas descrições
- Uma área de **contato via WhatsApp**

## Tecnologias utilizadas

- HTML
- CSS
- JS

## Objetivo

O objetivo deste projeto é praticar desenvolvimento web e iniciar a construção de um portfólio com projetos desenvolvidos durante meu processo de aprendizado.
